# mintwoche - random numbers and security
Why a bad random number generator makes any encryption worthless. Needs numpy, matplotlib, pycryptodomex.

| Folder | Contents |
|---|---|
| `problem_1_randu_key/` | rebuild an AES key from RANDU output and decrypt the message |
| `problem_2_seed_bruteforce/` | brute-force the `random` seed that generated an AES key |
| `plot_scripts/` | code that draws the plots, including the three generator comparisons |
| `plots/` | rendered plots |
| `test/` | RANDU implemented from scratch as an installable package |
